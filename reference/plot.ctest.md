# Plot the CTest posterior distributions

Plot the CTest posterior distributions

## Usage

``` r
# S3 method for class 'ctest'
plot(x, ...)
```

## Arguments

- x:

  CTest result to plot: the output of
  [`ctest`](https://stratigraphy.github.io/WaverideR/reference/ctest.md)
  (an object of class `ctest`). Required, no default.

- ...:

  Not used; present for compatibility with the generic `plot` function.
