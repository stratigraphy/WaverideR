# La2004 polynomial extrapolation (Laskar et al. 2004, eqs. 39-40) Strictly valid only over a few hundred Myr; shown for comparison.

La2004 polynomial extrapolation (Laskar et al. 2004, eqs. 39-40)
Strictly valid only over a few hundred Myr; shown for comparison.

## Usage

``` r
la2004_extrap(age_ma)
```

## Arguments

- age_ma:

  Age or ages in Ma (numeric vector, \>= 0; positive into the past); one
  output row per age. The polynomials are only reliable over the last
  few hundred Myr. Required (no default).
