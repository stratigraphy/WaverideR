# Plot an adaptive COCO result

Correlation, global and local p, contributing periods and pCOCO against
sedimentation rate.

## Usage

``` r
# S3 method for class 'coco_adaptive'
plot(x, ...)
```

## Arguments

- x:

  Adaptive COCO result to plot: the output of
  [`coco_adaptive`](https://stratigraphy.github.io/WaverideR/reference/coco_adaptive.md)
  (an object of class `coco_adaptive`). Required, no default.

- ...:

  Not used; present for compatibility with the generic `plot` function.

## Value

invisible NULL
