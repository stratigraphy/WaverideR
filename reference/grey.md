# Grey scale record IODP 926 of Zeeden et al., (2013)

IODP 926 grey scale record of Zeeden et al., (2013) for the (154-174m)
interval. The (154-174m) interval spans the Miocene.

## Details

Column 1: depth (meters)  
Column 2: greyscale value
