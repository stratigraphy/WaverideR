# Example anchor points for the grey scale data set of Zeeden et al., (2013)

An example of anchor points generated using
[`astro_anchor`](https://stratigraphy.github.io/WaverideR/reference/astro_anchor.md)
function  
The anchor points were generated for the
[`grey`](https://stratigraphy.github.io/WaverideR/reference/grey.md)
grey data set of  
Zeeden et al. (2013) and anchored to the
[`astrosignal_example`](https://stratigraphy.github.io/WaverideR/reference/astrosignal_example.md)  
astronomical solution which is a pre-generated ETP
(eccentricity-tilt-precession)  
solution(p-0.5t based on the la2004 solution) based on Laskar et al.,
(20004)  
astronomical solution.

## Details

Column 1: depth proxy record  
Column 2: time astronomical solution  
Column 3: y-scale value proxy record  
Column 4: y-scale value astronomical solution
