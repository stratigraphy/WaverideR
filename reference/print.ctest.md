# Print a CTest result

Print a CTest result

## Usage

``` r
# S3 method for class 'ctest'
print(x, ...)
```

## Arguments

- x:

  CTest result to print: the output of
  [`ctest`](https://stratigraphy.github.io/WaverideR/reference/ctest.md)
  (an object of class `ctest`). Required, no default.

- ...:

  Not used; present for compatibility with the generic `print` function.

## Value

x, invisibly
