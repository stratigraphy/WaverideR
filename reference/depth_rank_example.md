# An example depth rank series

The `depth_rank_example` example data set is a depth rank series which  
can be used as input for the
[`lithlog_disc`](https://stratigraphy.github.io/WaverideR/reference/lithlog_disc.md)
function which creates a  
discritzed record which can then be used as input in the
[`analyse_wavelet`](https://stratigraphy.github.io/WaverideR/reference/analyse_wavelet.md)  
function

## Details

Column 1: depth (meters)  
Column 2: depth rank
