# Plot an astro_sedrate_multi result

Combined significance spectrum (-log10 same-rate p) per section with its
family-wise 5 % level, and the significance spectra of the single
components (thin lines).

## Usage

``` r
# S3 method for class 'astro_sedrate_multi'
plot(x, ...)
```

## Arguments

- x:

  Result to plot: an object of class `astro_sedrate_multi`, as returned
  by
  [`astro_sedrate_multi`](https://stratigraphy.github.io/WaverideR/reference/astro_sedrate_multi.md).
  Required, no default.

- ...:

  Not used; present for compatibility with the generic
  [`plot()`](https://rdrr.io/r/graphics/plot.default.html).

## Value

A plot.
