# The Pridoli example: the four terms resolved at Cellon (Carnic Alps) on the astrochronozone time scale of Arts and Da Silva.

The Pridoli example: the four terms resolved at Cellon (Carnic Alps) on
the astrochronozone time scale of Arts and Da Silva.

## Usage

``` r
example_pridoli(file = NULL)
```

## Arguments

- file:

  Path of an output file for the final figure, passed to
  [`plot_astro`](https://stratigraphy.github.io/WaverideR/reference/plot_astro.md)
  (character): a name ending in `".png"` writes a PNG file, any other
  name a PDF file; `NULL` draws on the current device. `Default=NULL`.
