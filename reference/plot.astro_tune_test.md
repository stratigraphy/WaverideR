# Plot an astro_tune_test result

Rate path with its 95% band, the age model with its 95% band, and the
observed statistics against the surrogates.

## Usage

``` r
# S3 method for class 'astro_tune_test'
plot(x, ...)
```

## Arguments

- x:

  Result to plot: an object of class `astro_tune_test`, as returned by
  [`astro_tune_test`](https://stratigraphy.github.io/WaverideR/reference/astro_tune_test.md).
  Required, no default.

- ...:

  Not used; present for compatibility with the generic
  [`plot()`](https://rdrr.io/r/graphics/plot.default.html).

## Value

No return value, called for the plot.
