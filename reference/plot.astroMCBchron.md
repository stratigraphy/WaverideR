# Plot an astroMCBchron model

Three panels: (A) age model (95% range) with the dates and, if present,
the modBchron model; (B) 2 sd age uncertainty of both models; (C)
posterior and leave-one-out ages minus the dates. Oldest strata/ages on
the left and bottom.

## Usage

``` r
# S3 method for class 'astroMCBchron'
plot(x, ...)
```

## Arguments

- x:

  an `astroMCBchron` object.

- ...:

  unused.
