# Plot a COCO result (Li et al. 2018 method)

Correlation, H0 significance, number of contributing parameters and
pCOCO against sedimentation rate.

## Usage

``` r
# S3 method for class 'coco_classic'
plot(x, ...)
```

## Arguments

- x:

  COCO result to plot: the output of
  [`coco_classic`](https://stratigraphy.github.io/WaverideR/reference/coco_classic.md)
  (an object of class `coco_classic`). Required, no default.

- ...:

  Not used; present for compatibility with the generic `plot` function.

## Value

invisible NULL
